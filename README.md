# 《开心消消乐》活动配置与推送机制研究报告

本项目为针对国民级消除手游《开心消消乐》（Happy Elements Anipop v1.162）客户端核心逻辑的解包逆向与活动运营工程审查报告。

## 核心研究成果

1. **统一弹窗队列生命周期（AutoPopupLimit）**：
   - 场景二（登录/进主界面）：最多允许弹出 4 次，全局冷却间隔为 300 秒（5 分钟）。
   - 场景三（准备进关）：前置阻断判定（`checkPopOnStage3` 硬编码 `return false`）。
   - 场景四（关卡结算/出关）：专享单次（1次）弹窗预算，保障玩家连胜心流体验。
2. **多维玩家分层底座（UserTagManager & UserTagTracker）**：
   - 7 维独立画像体系：历史累计付费（5档）与近期付费周期（7档）、活跃与召回状态、单活动参与深度（$L_1 \sim L_4$）、云端 DP 数据平台打标（114项）、本地行为统计、关卡进度聚类及 A/B 实验分桶。
3. **端云权责与防疲劳体系**：
   - 4 级证据链边界（包内硬编码、远端下发执行、服务端黑盒计算、渠道差异）。
   - 本地 Local Push 避开夜间免扰时段（22:00 ~ 07:00），在次日 08:00 与 20:30 黄金时段集中调度。
   - 新关卡上线前 4 小时免打扰沉浸保护。
